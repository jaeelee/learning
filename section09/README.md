# useReducer

- 컴포넌트 내부에 새로운 state를 생성하는 react hook
- 모든 useState는 useReducer로 대채 가능

## 차이점

| useState                                   | useReducer                                     |
| ------------------------------------------ | ---------------------------------------------- |
| 상태관리 코드는 컴포넌트 내부에 작성해야함 | 컴포넌트 외부에 상태관리 코드를 분리할 수 있음 |

## 왜씀?

-> React 컴포넌트의 메인역할 : UI렌더링

-> 상태관리 코드가 많아지면 주객이 전도된 느낌

-> 가독성이 떨어짐

-> 컴포넌트가 어떤 ui를 렌더링하는지 파악하기 어렵고 유지보수 힘듦

-> useReducer를 통해 상태관리를 분리
