## Counter 앱 만들기

### state Lifting (state 끌어올리기)

-> 컴포넌트는 계층구조이다

- 형제 컴포넌트끼리는 데이터를 전달할 방법이 없다
- 리액트는 컴포넌트간의 데이터 전달을 하기위해서는 props를 활용한다.
- props는 부모에서 자식으로만 전달 가능하다.
- props로 데이터를 전달하기 위해서는 부모 자식 관계여야하기 때문에
- App컴포넌트에 상태값을 만들어주고 props로 viewer와 controller 컴포넌트에 넘겨줘야한다.

  => 결론: 하나의 스테이트를 여러 컴포넌트에서 관리하는 경우 반드시 공통 부모로가 되는 곳에 state를 만들어야 한다.
  => 데이터들은 위에서 아래로 하나의 방향으로만 흐른다 -> 단방향 데이터 흐름 -> 데이터의 흐름을 파악하기 쉽고 직관적임
